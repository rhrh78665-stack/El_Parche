RNF-10

Pruebas pendientes en Windows 10 o superior y Android 10 o superior con pantalla mínima de 5,5 pulgadas. Ejecutar registro, cocina, cobro, compra, receta y cierre. Comprobar teclado, selección, scroll, foco, zoom y orientación. El servidor usa Python 3.12+; los dispositivos cliente usan navegador con módulos ES, IndexedDB y service worker. El modo offline requiere HTTPS confiable o localhost. Los estilos incluyen alternativa opaca si el navegador no admite desenfoque. No se declara compatibilidad demostrada solo por usar CSS adaptable.
